# Repository instructions

For any review or edit of `docs/paper*/`, read `.claude/skills/paper-claims/SKILL.md` first.
Preserve coherent contributions. Do not infer that length or contribution count is a defect;
when a claim is vulnerable, try to earn it with a proof, experiment, independent unit, or
clearer integration before weakening it. Remove material only for a demonstrated contradiction,
duplication, lack of evidential function, or an explicit venue constraint.
