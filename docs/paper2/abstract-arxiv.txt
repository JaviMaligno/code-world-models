In the Code World Model (CWM) paradigm an LLM synthesizes an executable world model that a classical planner searches, accepted when it matches sampled transitions. In discrete games, a companion paper showed this gate certifies the wrong thing: a model can pass at 100% transition accuracy and still lose, following danger = play_cost x (1-rarity)^N. This paper moves to continuous state spaces, where model-based RL treats world-model error as pervasive, not localized. The law transfers (its ingredients are measure-theoretic) and we prove smooth (Lipschitz) pairs cannot realize the exactly localized verified-but-wrong geometry: exact localization needs unbounded local Lipschitz structure, which hybrid boundaries supply, so an omitted mode is a rare rule. On two 1D hybrid instruments the gate misses the mode at the predicted (1-r)^N rate, the mode-blind planner is exploited below random at every knob once the phantom reward's tail is removed, play_cost knob-invariant to 1e-4; a distrust-region planner collapses this to a single-contact transient (separation, not covering). With real LLM synthesis, on 1D every mode-missing sample yielded a certified, blind, exploited model; when it contained the mode, GPT-5.x repaired the exact rule (109/111) -- unlike the discrete setting. But repair is geometry-dependent: on a 4D bi-modal instrument with 2D modes it inverts. Neither GPT-5.x size recovers the region rule in 156 attempts over 20 mode-containing samples (disc, square, 3x budget); a Claude arm fails likewise. The mechanism is a template prior over low-complexity regions (half-planes on the disc, discs on the square), not boundary curvature, so the law's exhaustiveness is geometry-scoped; certification stays sound. Identifiability is a sample property; repair is model- and geometry-dependent. Localization -- both the danger and the repair -- is a representational property of code.
