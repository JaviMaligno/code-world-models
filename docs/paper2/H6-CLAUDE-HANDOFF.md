# H6 handoff — explicit exclusion matrix

H6 is implemented locally because the Claude Code workspace exhausted its credits after the H3
run. This file records that provenance rather than implying Claude performed this step.

The canonical ledger is `results/h6_exclusion_matrix_v1.json`, generated by
`scripts/h6_exclusion_matrix.py` and checked by `tests/test_h6_exclusion_matrix.py`. It records, for
all eight interventions, the target hypothesis, all changed variables and co-changes, prediction
status, experimental unit, positive control, observed result, strongest licensed inference, and
the inference that is *not* licensed.

The strengthened conclusion is positive and specific: on every widest-coverage block the declared
least-squares circle estimator recovers the located rule, while the two synthesis conditions recover
it in 0/40 draws; once form and location are supplied, synthesis recovers the withheld radius in
20/20. The matrix does not identify a unique internal mechanism. In particular, the slab excludes
nothing about arity because its target is observationally non-identifiable.

Four factorial follow-ups are specified in the JSON: disentangle prompt from budgets; cross
post-state semantics with calibrated evidence dose; separate angular coverage from start law; and
cross trigger arity with identifiability using a bounded one-coordinate region.

Run:

```bash
PYTHONPATH=src .venv/bin/python scripts/h6_exclusion_matrix.py
PYTHONPATH=src .venv/bin/python scripts/h6_exclusion_matrix.py --check
PYTHONPATH=src .venv/bin/python -m pytest tests/test_h6_exclusion_matrix.py -q
```
